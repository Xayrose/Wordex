# Wordex — декор для документов

**Сайт:** https://xayrose.github.io/Wordex/

Публичная библиотека декоративных элементов для оформления документов Word и Google Docs. На сайте доступны поиск, тематические категории, просмотр элементов, скачивание и копирование.

## Публикация

Проект использует GitHub Pages. Workflow в `.github/workflows/deploy-pages.yml` запускает деплой при изменениях в `main` и вручную через Actions.

Если сайт не публикуется автоматически, открой **Settings → Pages** и выбери публикацию через **GitHub Actions**.
